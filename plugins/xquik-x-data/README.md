# xquik-x-data

This plugin helps Claude Code use current Xquik REST API and remote MCP setup guidance for X data workflows.

## Use Cases

- REST API and SDK setup.
- Remote MCP setup.
- Tweet search, user lookup, and timeline reads.
- Exports, monitors, and webhooks.
- Approval-gated X action planning.

## Setup

Set `XQUIK_API_KEY` before using the optional MCP config. Do not put API keys in chat, logs, examples, commits, or pull requests.

## Source Checks

- Docs: https://docs.xquik.com
- OpenAPI: https://xquik.com/openapi.json
- MCP manifest: https://xquik.com/.well-known/mcp.json
- MCP endpoint: https://xquik.com/mcp
